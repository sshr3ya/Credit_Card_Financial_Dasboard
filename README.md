#  Credit Card Financial Dashboard

## Overview
Power BI dashboard analysing credit card customer and transaction data to understand revenue, customer behaviour, and transaction trends.

##  Tools
SQL • PostgreSQL • Power BI • DAX

##  Analysis
* Customer demographics
* Revenue & transaction trends
* Card category performance
* Transaction methods
* Customer satisfaction
* Delinquent accounts

##  Key Insights
Identifies high-value customer segments, revenue trends, transaction patterns, and card performance.

Skills:  SQL • PostgreSQL • Power BI • DAX • Data Analysis
